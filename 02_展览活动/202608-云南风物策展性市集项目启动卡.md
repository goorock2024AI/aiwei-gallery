# 云南风物策展性市集项目启动卡

- 项目状态：待馆长/集团确认后启动
- 优先级：P1
- 建议档期：2026年8月下旬至10月，重点覆盖中秋、国庆消费窗口
- 使用空间：艾维美术馆一号展厅
- 项目性质：纯商业活动，采用艺术策展方式组织“展览 + 销售 + 招商入驻”的策展性市集
- 当前版本：v0.1，2026-07-28

## 一、已确认事实

1. 集团公司提出要求：2026年8-10月期间，在美术馆举办一次纯商业活动。
2. 活动主题方向为“云南风物”。
3. 活动使用一号展厅。
4. 活动形态不是普通摊位市集，而是用艺术策展方式组织“展览 + 销售”的商业活动。
5. 商业模式以招商引入商家为核心。
6. 云南重彩画展已延期，原先与9月重彩画展的直接档期冲突降低；新的重彩画展档期仍待确认。

## 二、待确认事项

1. 集团对收入目标的要求：保底收入、分成收入、品牌曝光或综合经营目标。
2. 一号展厅在8-10月的可用档期，以及云南重彩画展延期后的新档期。
3. 招商对象边界：是否限定云南品牌、非遗手作、茶咖酒食、文创、生活方式、艺术衍生品。
4. 招商收费模型：展位费、销售抽成、联合套餐、品牌赞助、活动冠名是否可组合。
5. 现场销售资质、食品经营、临时搭建、消防通道、收银结算和合同主体。
6. 是否允许商家自行布置，或必须统一视觉和陈列标准。

## 三、项目判断

这个项目不宜按“摆摊招商”理解，而应做成“可购物的云南风物展”。美术馆的价值在于给商业活动提供策展结构、审美秩序、内容叙事和观众信任，招商卖点也应从“租一个摊位”升级为“进入一个被策展包装的云南生活美学场景”。

云南重彩画展延期后，本项目的战略价值上升：它可以作为8-10月一号展厅的商业填档项目，承担假期客流、招商收入和美术馆空间活化功能。后续不应再等待重彩画展完全落定后才启动招商，而应先按独立商业项目推进，同时保留与重彩画展新档期联动的可能。

建议项目名称暂定为：

**《云南风物集：可带走的地方美学》**

备选名称：

1. **云南风物集**
2. **云上风物市**
3. **有物自云南**
4. **云南风物志：市集篇**

## 四、策展概念

主题句：

**把云南的自然、手艺、味道与日常器物，组织成一个可以观看、可以体验、可以买走的艺术现场。**

策展逻辑建议分为四个单元：

| 单元 | 内容方向 | 可招商品类 | 展陈方式 |
|---|---|---|---|
| 山野之味 | 云南茶、咖啡、菌菇、香料、花果、地方饮品 | 茶咖品牌、伴手礼、轻食、地方特产 | 气味、器皿、产地地图、试饮试吃 |
| 手作之形 | 非遗、民族手工艺、织绣、陶器、银饰、竹木器 | 手作品牌、非遗工坊、设计师品牌 | 展柜 + 工艺过程展示 |
| 色彩之境 | 云南重彩、民族色彩、植物染、图案纹样 | 艺术衍生品、家居软装、服饰配饰 | 色彩墙、图案样本、作品联动 |
| 生活之物 | 花艺、香氛、文创、旅行生活方式 | 花艺、香氛、文创、户外生活方式品牌 | 场景化陈列和组合销售 |

## 五、商业模型建议

建议使用“基础展位费 + 销售抽成 + 品牌权益包”的组合模型，避免只靠单一摊位费。

| 类型 | 适合对象 | 收费方式 | 权益 |
|---|---|---|---|
| 标准入驻商家 | 文创、手作、伴手礼、生活方式品牌 | 固定展位费 + 销售抽成 | 展位、统一导视、基础传播露出 |
| 重点品牌展陈 | 茶咖、非遗、设计师品牌 | 较高展位费或保底合作 | 独立陈列区、专场活动、内容采访 |
| 主题赞助商 | 本地企业、文旅、酒饮、金融、车企 | 赞助费 | 冠名/联合主办/贵宾专场/物料露出 |
| 快闪活动合作 | 工作坊、品鉴会、讲座、体验课 | 场次费或票房分成 | 使用活动区、报名收款、现场转化 |

招商定价需要馆长确认后才能对外承诺。建议先用“意向招商包”沟通，正式价格在成本测算和权益确认后发布。

## 六、空间使用建议

一号展厅不建议做满铺式摊位，应保留展览感和动线。

建议结构：

1. 入口：主题视觉、项目介绍、云南风物地图。
2. 主动线：四个策展单元顺序展开，形成“看展式逛市集”。
3. 中央区：重点品牌或主视觉装置，作为拍照传播点。
4. 边界区：标准商家陈列位，统一高度、灯光、标识和收银规则。
5. 尾厅：收银/服务台、会员转化、活动报名、企业合作咨询。

## 七、招商对象初筛标准

建议优先选择符合以下标准的商家：

1. 与云南地域文化、物产、工艺、生活方式有真实关联。
2. 产品视觉和品质能进入美术馆展陈环境。
3. 具备稳定供货和现场销售能力。
4. 能配合统一陈列、价格标识、收银或销售数据回传。
5. 愿意提供内容素材：品牌故事、产地信息、工艺过程、产品图片。

不建议引入：

1. 与主题弱相关的普通零售摊位。
2. 现场气味、油烟、噪音或人流风险较高的商家。
3. 无法提供资质或产品来源说明的食品、酒饮、保健类商品。
4. 陈列风格明显破坏美术馆空间品质的低价杂货摊。

## 九、任务卡

### YF-001 项目立项与边界确认

- 优先级：P1
- 状态：等待馆长决定
- 执行单元：馆长/集团决策 + 总协调
- 截止日期：2026-08-02

交付物与验收标准：

| 交付物 | 完成定义 | 证据位置 |
|---|---|---|
| 项目立项确认 | 明确活动名称、档期、空间、收入目标、集团要求 | 本文档更新记录或会议纪要 |
| 一号展厅档期确认 | 明确重彩画展延期后一号展厅8-10月可开放给本项目的时间段 | 展厅排期表 |
| 商业边界确认 | 明确收费、分成、合同、收银、食品/酒饮限制 | 决策记录 |

需要馆长决定：

1. 是否将该项目作为8-10月商业经营重点项目启动。
2. 收入目标按“保守/标准/冲刺”三档中的哪一档制定。
3. 云南重彩画展延期后，本项目是否先作为独立商业项目启动，并保留后续联动空间。

### YF-002 招商产品包

- 优先级：P1
- 状态：待启动
- 执行单元：商务合作/总协调
- 截止日期：2026-08-07

交付物与验收标准：

| 交付物 | 完成定义 | 证据位置 |
|---|---|---|
| 招商方案 | 包含项目定位、空间权益、商家类型、收费模型、传播权益 | 招商方案文档 |
| 招商报价表 | 至少包含标准展位、重点品牌、主题赞助、快闪活动四类 | 报价表 |
| 商家邀约话术 | 可直接用于微信/电话沟通 | 招商话术文档 |

风险：

1. 未确认价格前不得对外承诺。
2. 商家权益过多会挤压美术馆运营能力。
3. 纯商业活动如果缺少策展包装，会降低美术馆品牌感。
