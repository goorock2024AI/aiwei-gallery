# M3-02 数据结构迁移脚本说明

本迁移包用于 2.0「美术馆运营管理」的数据结构准备，只生成新增结构、扩展字段、事实视图、验证脚本和回滚脚本。

## 文件顺序

1. `20260903_m3_02_business_dimensions.sql`
   - 新增业务维度字典表。
   - 新增业务映射规则表。
   - 新增原始记录到业务分类的人工修正表。
   - 写入 M1 已冻结的一级业务层、业务类型、成本类型、能力轴。

2. `20260903_m3_02_product_gallery_space_extensions.sql`
   - 新增商品别名表。
   - 为文创商品、画廊销售、空间使用记录增加 2.0 扩展字段。
   - 仅使用 `ADD COLUMN IF NOT EXISTS`，不修改 1.0 原始字段含义。

3. `20260903_m3_02_business_fact_views.sql`
   - 新增 `business_revenue_facts_v2`。
   - 新增 `business_cost_facts_v2`。
   - 新增 `business_profit_facts_v2`。
   - 视图用于 M3 之后的统计、诊断和 3.0 可视化准备。

4. `20260903_m3_02_validate.sql`
   - 只读验证脚本。
   - 检查核心表行数、新对象存在性、扩展字段、事实视图金额、重复 fact_id、映射质量和缺失成本。

5. `20260903_m3_02_rollback.sql`
   - 回滚 M3-02 新增视图、表和扩展字段。
   - 不删除 1.0 基础业务数据，不删除 1.0 原始字段。

## 执行边界

当前阶段只完成脚本开发和静态审阅，不执行生产迁移，不做历史数据回填，不切换前端功能入口。

执行前必须完成数据库备份，并先在本地或测试库演练：

```bash
psql "$DATABASE_URL" -f 20260903_m3_02_business_dimensions.sql
psql "$DATABASE_URL" -f 20260903_m3_02_product_gallery_space_extensions.sql
psql "$DATABASE_URL" -f 20260903_m3_02_business_fact_views.sql
psql "$DATABASE_URL" -f 20260903_m3_02_validate.sql
```

M3-03 推荐使用项目脚本统一执行演练：

如本机尚未安装 PostgreSQL 测试环境，可先执行安装脚本：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/m3-03-install-local-postgres.ps1 -RunPreflightAfterInstall
```

安装脚本默认安装 PostgreSQL 17，使用本地端口 `55432`，创建 `aiwei_m3_03_test` 测试库，并把本地连接信息写入 `tmp/m3-03-local-postgres.env`。该文件不得提交。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/m3-03-preflight-check.ps1 -DatabaseUrl "<local-or-test-database-url>"
```

preflight 通过后再执行完整演练：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/m3-03-local-migration-rehearsal.ps1 -DatabaseUrl "<local-or-test-database-url>"
```

完整演练脚本默认会执行初始化、迁移、验证、回滚和回滚后重建检查，并且不会打印数据库连接信息。

如果本机没有 `psql`，但已安装 Node 依赖，可以使用 Node 版演练：

```powershell
$env:AIWEI_TEST_DATABASE_URL="<local-or-test-database-url>"
npm run m3:rehearsal
```

Node 版演练同样默认执行初始化、迁移、验证、回滚和回滚后重建检查。
