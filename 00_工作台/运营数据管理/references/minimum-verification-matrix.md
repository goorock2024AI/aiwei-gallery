# 最小必要验证矩阵

## 前端静态热修

必须验证：

- 相关 JS 通过 `node --check`。
- 有专项逻辑脚本时运行专项脚本。
- `node scripts/check-dist-sync.js` 通过。
- 本地预览或 HTTP 拉取确认入口 HTML 命中新 token。
- 发布后确认远端文件 mtime/size。
- 发布后 HTTPS 拉取入口 HTML 和改动静态文件。
- 至少一个关键只读 API 返回 200。
- API 日志无 SyntaxError/ReferenceError。

不默认验证：

- 生产写入流程。
- 多浏览器截图。
- 多种命令重复拉取同一个静态文件。

## 后端 API 热修

必须验证：

- `node --check server.js`。
- 涉及的成功、失败、异常输入至少各一个 API 场景。
- 容器重建并运行。
- API 日志无启动错误。
- 前端入口可用。

## 数据库/财务变更

必须验证：

- 生产前备份或导出影响范围。
- SQL 预演或只读核对。
- 正式执行记录。
- 相关 REST 表/视图返回 200。
- 写入 smoke test 及清理证据。
- 回滚边界和不可回滚风险。

## 线上排障

必须验证：

- 先用只读探针确认当前线上事实。
- 区分静态文件、API、数据库、浏览器缓存、权限问题。
- 只有根因明确后才修改文件或执行生产动作。
