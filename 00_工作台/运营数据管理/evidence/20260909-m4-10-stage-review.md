## 安全边界验证

- 商品别名的歧义和无候选记录没有标准商品结论。
- 只有成交快照可以形成历史成本观察值；当前商品成本没有倒推到历史。
- 混合用途空间继续标记为人工复核。
- 收入冲突、成本冲突和部分规则候选均无法创建应用批次。
- editor 可以创建、dry-run 和提交；editor 审批返回 403，只有 admin 可以批准、应用和撤销。
- 阶段批次对一条收入和一条成本候选完成 create → dry_run → submit → approve → apply → revert，事件表与可信 `operation_logs` 的动作和操作者一致。
- 应用只新增两条 `record_business_links` 解释，撤销后恢复为零；收入、支出、画廊、空间、收款和日结的行数与核心金额前后完全一致。
