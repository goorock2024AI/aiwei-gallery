# M4-05 历史收入归属复核

- 日期：2026-09-08
- 版本：`2.0.0-dev.m4-05.1`
- 分支：`codex/operations-v2`
- 环境：本地隔离 PostgreSQL `aiwei_m3_05_test`，未连接生产

## 交付

1. 新增 `revenue_attribution_candidates_v2`，逐条定位未归类收入并生成稳定候选 ID。
2. 候选包含人工链接或规则来源、命中字段和值、优先级、置信度、建议业务层/类型、影响金额和原始来源定位。
3. 区分已有人工归属、人工归属待补、人工归属冲突、唯一规则候选、规则冲突和无候选。
4. 新增安全正则匹配函数；无效正则规则按不匹配处理，不导致整张治理视图失败。
5. 数据看板按当前年/月显示候选汇总、状态筛选和 CSV 导出。
6. editor/admin 可读；viewer 拒绝，两张新增对象不提供业务写入入口。

## 归属规则

| 情况 | 结果 |
|---|---|
| 已有唯一有效人工链接 | 人工归属优先，等待后续应用批次采用解释 |
| 人工链接未填写业务类型 | 保持待补，不回退到自动规则 |
| 多个人工链接指向不同归属 | 标记人工归属冲突 |
| 最高优先级规则指向同一归属 | 形成唯一规则候选，等待确认 |
| 最高优先级规则指向不同归属 | 标记规则冲突，禁止自动归属 |
| 没有有效规则 | 要求创建单条人工链接或补充规则 |
