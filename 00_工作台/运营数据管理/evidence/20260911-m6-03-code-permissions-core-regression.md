## 3. 本次发现与修正

1. Node 24 在公共请求路径记录了 `url.parse()` 安全弃用警告。`server.js` 已改用标准 `URL`/`URLSearchParams`，并显式保留重复参数的数组语义；修正后 M6、M3、M4、M5 API 回归全部通过，服务启动不再出现该警告。
2. M4 浏览器阶段脚本硬编码 `m4-10.1`，会把正常版本升级误报为失败。脚本现从仓库 `VERSION` 读取当前版本，M6-03 页面版本验证通过。
3. M4 阶段总评审需要七类确定性候选夹具。专用测试库的旧夹具已被清理后，总评审会明确失败；本次先顺序执行八组 M4 迁移专项准备环境，再执行阶段评审。后续复验必须保留这个显式顺序，不能依赖测试库残留。
