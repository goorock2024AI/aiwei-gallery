# M4-03 历史商品别名候选

- 日期：2026-09-08
- 版本：`2.0.0-dev.m4-03.1`
- 分支：`codex/operations-v2`
- 环境：本地隔离 PostgreSQL `aiwei_m3_05_test`，未连接生产

## 交付

1. 新增只读视图 `product_alias_candidates_v2`，按标准化历史商品名和历史售价聚合零售明细。
2. 输出 `matched`、`unique_candidate`、`ambiguous`、`no_candidate` 四种复核状态。
3. 每组包含稳定候选 ID、匹配依据、置信度、候选 JSON、影响明细/记录/数量/金额和日期范围。
4. 数据看板新增全历史商品别名候选卡，提供状态筛选和当前筛选结果 CSV 导出。
5. API 仅向 editor/admin 开放读取；viewer 拒绝，视图写入统一拒绝。

## 匹配边界

- 商品名先去除空白并忽略大小写，再与启用商品的名称或标准名精确比较。
- 售价仅在精确同名商品中辅助消歧；同价但不同名不会形成候选。
- 已有有效别名或销售时快照/人工链接保留为已匹配。
- 多个精确同名候选保留完整候选清单，不返回单一建议。
- 候选视图不写入 `product_aliases`，不修改 `creative_products` 或 `revenue`。
