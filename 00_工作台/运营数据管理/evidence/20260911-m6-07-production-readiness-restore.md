# M6-07 生产前置包与恢复演练证据

日期：2026-09-11
版本：`2.0.0-dev.m6-07.1`
范围：本地专用 PostgreSQL 17 测试库；未连接生产、未部署、未推送

## 交付结果

发布前置检查核对 Docker/API 模块、静态文件、版本、备份脚本和迁移文件。20 个正向迁移、16 个回滚文件及其规范化 LF SHA-256 全部匹配，`app` 与 `dist` 同步。发布脚本修正了首次组包前调用版本注入导致目标目录不存在的问题，并改为只修改临时包中的 API 地址，不再修改源码工作区。

API 新增无需登录的 `/healthz`，执行真实 `SELECT 1`：本地请求返回 HTTP 200 和 `{"status":"ok"}`。Docker Compose 以该端点判定 API 健康，Nginx 等待 API 健康后启动；部署脚本的数据库和 API 就绪检查超时后会失败退出。

## 边界与结论

本机没有可用 Docker/Bash，因此本任务没有本地构建容器镜像；API、Node 脚本、PowerShell 语法、真实 PostgreSQL custom dump 和恢复链分别验证。生产脚本没有执行。
