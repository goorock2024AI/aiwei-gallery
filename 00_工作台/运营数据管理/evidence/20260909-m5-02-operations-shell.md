# M5-02 运营管理入口与页面框架证据

完成日期：2026-09-09

版本：`2.0.0-dev.m5-02.1`

环境：本地静态应用、隔离 PostgreSQL `127.0.0.1:55435/aiwei_m3_05_test`、本地 API `127.0.0.1:3121`、Microsoft Edge；未连接生产环境。

## 交付结果

- 侧栏新增“运营管理”独立入口，保留原“数据看板”。
- 新增 `page-operations` 页面容器和独立 `operations-dashboard.js` 模块。
- 页面顶部展示产品定位、当前期间和本地数据范围；年月筛选可更新整个页面的期间状态。
- 建立经营总览、四层经营矩阵、趋势与口径比较、数据治理工作台、业务模型对应、明细与导出六个内容区。
- 分区导航可滚动并将键盘焦点移至目标区域，刷新操作通过 `aria-live` 返回当前期间状态。
- admin/editor 显示入口，viewer 隐藏入口；页面本身保持只读。
- 三套静态目录的入口、样式、路由、权限和页面模块已同步，版本更新为 `2.0.0-dev.m5-02.1`。

M5-02 只建立可用页面框架。经营金额、趋势、治理摘要和下钻数据将在后续任务按冻结数据源接入，当前页面不伪造经营指标。
