# 艾维美术馆项目进化工作计划（2026年7月-10月）

更新时间：2026-07-21  
计划周期：2026-07-21 至 2026-10-31  
计划性质：以经营稳定、项目可控、国庆展览落地为目标的 90 天执行计划。

## 一、计划背景与核心判断

艾维美术馆已经具备空间、展览内容、旅游客流窗口与一套正在使用的运营数据系统；当前的主要问题不在于“没有项目可做”，而在于项目、资金、数据与责任人尚未形成同一套可追踪的经营闭环。

截至 2026-07-21，运营收入已产生真实数据，但收入具有明显季节性，票务仍是重要来源；云南重彩画展方向已经确定，但负责人、预算、作品清单、赞助推进尚未收口；运营系统已上线并持续迭代，但财务闭环、权限与备份仍是经营风险点。未来 90 天的目标，是把美术馆从“靠人推进的项目集合”升级为“有经营节奏、有项目台账、有复盘能力的运营组织”。

## 二、90天总目标

| 目标 | 10月31日前的完成定义 | 关键衡量指标 |
|---|---|---|
| 项目治理 | 所有进行中项目进入统一线上台账，并有唯一负责人、状态、下一节点和预算口径 | 进行中项目台账覆盖率 100%；无负责人项目为 0 |
| 国庆展览 | 云南重彩画展完成策展、作品、预算、招商、传播、现场执行的闭环准备，并按计划开幕 | 关键里程碑按时完成率不低于 90% |
| 经营稳定 | 建立日结、周报、月度经营复盘，能看清各收入来源与应收风险 | 日结提交率 100%；月报在次月第 5 个工作日前完成 |
| 系统可靠 | 运营系统补齐基础安全、备份与关键财务动作 | HTTPS、接口鉴权、每日备份、退款/作废、库存扣减、日结可用 |
| 商业增长 | 围绕黄金周形成票务、活动、场租、文创和赞助的组合收入，而非单一依赖门票 | 国庆项目形成独立收入预算与实际复盘 |
| 文档可信 | 基础状态、项目库、工作日志、线上数据和 Git 版本形成固定更新节奏 | 每周更新按时率不低于 90% |

## 三、工作原则

1. 先把责任、预算、日期写清楚，再讨论执行细节；没有负责人和下一节点的事项不视为“进行中”。
2. 以现金流和观众体验共同校验项目价值。展览、活动、场租、文创和传播均应能说明其收入、获客或品牌目标。
3. 业务先闭环，再扩功能。运营系统以收款、退款、库存、应收、日结、备份为优先，不在关键链路未稳定时扩张非必要页面。
4. 一处事实源。项目状态以线上项目台账为准，策展与执行细节以专题文档为准，基础信息文档只保留稳定且已确认的事实。
5. 每周可见、每月复盘。问题在周会上暴露，资源和方向在月度经营会上决策，不让事项长期停留在“待确认”。

## 四、组织与决策机制

### 1. 建议角色设置

| 角色 | 建议职责 | 必须产出 |
|---|---|---|
| 馆长/经营决策人 | 批准预算、定价、合作、关键资源与取舍 | 月度经营决议、关键事项批复 |
| 项目总协调人 | 维护项目台账、主持周推进会、追踪跨部门阻塞项 | 周项目看板、会议纪要、风险清单 |
| 策展负责人 | 展览主题、艺术家、作品、学术文本、布展标准 | 策展执行包、作品清单、布展方案 |
| 商务负责人 | 赞助、场租、联名、渠道合作与合同推进 | 商务漏斗、报价单、合同台账 |
| 运营负责人 | 接待、票务、活动排班、现场流程、日结 | 排班表、日结表、活动复盘 |
| 财务/数据负责人 | 收支核对、应收跟踪、月报、数据质量 | 月度损益简报、应收账龄表、异常清单 |
| 系统负责人 | 运营系统迭代、发布、备份、权限、故障处理 | 发布记录、备份记录、问题清单 |
| 内容传播负责人 | 内容排期、媒体/KOL、社群、投放与转化追踪 | 月度内容日历、传播复盘、线索表 |

同一人可以兼任多个角色，但每个角色必须指定到具体姓名；不能只写“团队”或“待定”。负责人应在 2026-07-24 前填入项目台账。

### 2. 固定会议节奏

| 节奏 | 时长 | 参加人 | 只解决什么问题 | 固定输出 |
|---|---:|---|---|---|
| 每日营业快报 | 10分钟 | 运营、财务/数据 | 昨日收入、客流、异常、应收 | 日结记录 |
| 周项目推进会 | 45分钟 | 决策人、项目协调、各负责人 | 下两周节点、阻塞事项、需决策事项 | 项目台账更新、行动项 |
| 周经营检查 | 30分钟 | 馆长、运营、财务、商务 | 收入结构、现金、应收、转化与费用 | 经营周报 |
| 月度经营复盘 | 90分钟 | 核心负责人 | 本月结果、偏差原因、下月资源投放 | 月度经营简报、决议清单 |
| 展前专项会 | 每周 2 次 | 云南重彩画展全组 | 作品、施工、招商、传播、票务与现场风险 | 展览倒排表 |

会议不是“汇报会”：每项行动必须写明负责人、截止日和需要的支持；未关闭事项自动进入下一次会议首项。

## 五、五条工作主线

### 主线A：项目治理与统一台账

**目标：** 让每个项目可见、可问责、可判断是否继续投入。

| 动作 | 截止日期 | 负责人角色 | 交付物 | 验收标准 |
|---|---|---|---|---|
| 定义项目状态与字段标准 | 07-24 | 项目总协调人 | 《项目台账字段规范》 | 含项目名称、类型、负责人、状态、目标、预算、实际、下节点、风险、关联文档 |
| 补齐线上项目库 | 07-26 | 项目总协调人、系统负责人 | `project_registry` 初始台账 | 本地 `registry` 中的活跃/框架项目全部同步，线上空记录问题消除 |
| 建立项目命名规则 | 07-26 | 项目总协调人 | 命名规范 | `ops_project_name`、文档标题、合同/报表名称可互相对应 |
| 存量项目一次性清理 | 07-31 | 各项目负责人 | 项目分级清单 | 每项标为推进/暂停/结束；暂停项目写明恢复条件 |
| 每周更新项目台账 | 每周五 | 项目总协调人 | 周项目快照 | 每条活跃项目都有未来 14 天下一动作 |

建议状态统一为：`未开始 / 筹备中 / 执行中 / 待决策 / 暂停 / 已完成 / 已取消`。其中“待决策”不得超过 7 天；超过即由决策人明确取舍。

### 主线C：运营数据系统与财务闭环

**目标：** 让系统从“记录收入的工具”成为可对账、可追责、可恢复的经营基础设施。

| 优先级 | 动作 | 截止日期 | 验收标准 |
|---|---|---|---|
| P0 | 配置 HTTPS 与有效证书 | 07-31 | 所有业务入口强制 HTTPS，无浏览器安全警告 |
| P0 | 为 API 增加鉴权与角色权限 | 08-07 | 未授权请求不能读写经营数据；收银、运营、管理权限可区分 |
| P0 | 建立数据库每日自动备份和月度恢复演练 | 08-07 | 连续 7 日备份成功；完成一次恢复验证并留档 |
| P0 | 上线退款/作废审批与留痕 | 08-14 | 每笔退款/作废有操作人、原因、时间、关联原单 |
| P0 | 实现文创/零售库存扣减与采购入库 | 08-21 | 销售后库存可核，入库有成本与供应商记录 |
| P0 | 上线日结报表 | 08-21 | 日收入、支付方式、退款、现金差异、操作人可导出 |
| P1 | 建立应收与回款看板 | 08-31 | 场租、合作、赞助按合同、应收日、状态和账龄追踪 |
| P1 | 建立月度经营仪表盘 | 09-05 | 收入结构、客流、毛利/费用、应收、渠道转化可月度比较 |
| P1 | 完成移动端真机回归与版本标识 | 08-14 | 核心收银/核销流程在真机可用；页面显示版本与更新时间 |

**发布纪律：** 每次上线必须有版本号、变更说明、发布人、回滚方式和验证结果。2026-07-21 已部署但尚未纳入 Git 提交记录的内容，应先完成变更核对、提交和发布日志补齐，再继续叠加功能。

### 主线D：商业化与现金流

**目标：** 建立“展览引流、产品转化、合作回款、空间变现”的组合收入结构。

| 模块 | 7月目标 | 8月目标 | 9-10月目标 | 核心指标 |
|---|---|---|---|---|
| 门票/核销 | 统一票种和收入分类 | 上线预售与渠道码 | 国庆动态排班和每日复盘 | 到馆率、渠道成本、每客收入 |
| 活动/工作坊 | 梳理可复制产品 | 固化 2-3 个活动包 | 与展览主题联动售卖 | 报名率、毛利、复购/转介绍 |
| 场地招租 | 明确空间清单、报价和档期规则 | 对外招商资料上线 | 执行首批看场与签约 | 线索数、转化率、回款周期 |
| 文创/零售 | 清理 SKU、成本、库存 | 建立展览主题产品包 | 黄金周陈列与补货机制 | 售罄率、毛利率、库存周转 |
| 赞助/合作 | 建立 P0 目标清单 | 完成提案与拜访 | 权益交付与回款 | 管道金额、签约额、回款率 |

商业项目统一使用一页纸立项：目标客户、产品/权益、价格、成本、容量、销售渠道、负责人、预计回款日、失败止损点。对外报价不得在没有成本和审批口径的情况下临时决定。

**目标：** 让文档成为决策依据，而不是事后记录。

| 动作 | 节奏 | 负责人角色 | 验收标准 |

## 七、关键风险与预案

| 风险 | 预警信号 | 预案 | 升级人 |
|---|---|---|---|
| 展览延期或作品不足 | 08-08 前核心作品未确认 | 启用备选艺术家/作品池，压缩展陈规模，重算预算 | 馆长/经营决策人 |
| 预算失控 | 单项报价超过预算 10% | 停止非必要采购，启动替代供应商比价 | 馆长、财务 |
| 赞助未落地 | 08-15 前无实质商务推进 | 将赞助收入从基础预算剥离，按无赞助情形调整项目规模 | 馆长、商务 |
| 系统数据错误或丢失 | 对账差异、无备份记录、异常删除 | 暂停相关发布，恢复备份并人工核账 | 系统负责人、财务 |
| 黄金周接待失序 | 排班不足、库存不足、投诉增加 | 设高峰日负责人，预留兼职/志愿者和安全/补货方案 | 运营负责人 |
| 项目长期卡住 | 同一事项连续两周无动作 | 在周会上转为“待决策”，由决策人于 48 小时内取舍 | 项目总协调人 |
