# 艾维美术馆会员制艺术阅读会方案

更新时间：2026-07-23  
项目状态：方案已形成，待立项确认  
项目定位：以艺术类书籍为主轴、由外部主理人共创、面向昆明本地文化艺术爱好者的年度会员制阅读社群。

## 一、项目愿景

将美术馆六楼阅读空间转化为稳定发生的艺术阅读社群：会员不只参加一场活动，而是在全年持续进入艾维的展览、阅读、交流和观众共同体。

项目以艺术类书籍和主题讨论为核心，连接艺术家、展览、影像、策展、云南在地文化与当代生活。它不定位为普通读书会，也不以售卖图书为主要目标，而是成为美术馆建立本地观众关系、激活阅读空间和发展非票务收入的长期产品。

## 二、已确认的基本设定

| 项目 | 已确认内容 |
|---|---|
| 举办时间 | 每周六在美术馆阅读空间举办 |
| 内容主轴 | 艺术类书籍与艺术主题讨论 |
| 主要客群 | 昆明本地文化艺术爱好者；同时接受游客临时报名参加 |
| 合作方式 | 邀请外部主理人与美术馆合办 |
| 主理人职责 | 选题、阅读书单、带领讨论、个人社群动员 |
| 美术馆职责 | 品牌、场地、会员体系、招募、报名、饮品、现场体验、内容传播、会员数据与复盘 |
| 主理人收入 | 基础服务费 + 读书会会费收入分成 |
| 不参与分成 | 饮品、文创、书籍、艺术品及其他衍生消费 |
| 首期形式 | 先运行一个 3 个月的创始试读季，预先公布 12 场主题与书单 |
| 长期方向 | 试读季验证后，转为全年会员制阅读社群 |

## 三、产品结构

### 1. 首期产品：创始试读季

| 项目 | 建议标准 | 说明 |
|---|---|---|
| 周期 | 3 个月 | 连续 12 个周六 |
| 场次 | 12 场常规艺术阅读会 | 主题与书单在招募前公布 |
| 规模 | 20-30 位创始会员 | 保留少量访客席，不以坐满空间为目标 |
| 节奏 | 每周六下午 | 具体时段根据交通、空间与饮品服务能力确认 |
| 内容结构 | 主题导入、共读/讨论、主理人引导、自由交流 | 可结合当期展览、导览或视觉材料 |
| 核心目的 | 验证主理人匹配度、到场率、社群氛围、续费意愿与服务流程 | 不以一次性收入作为唯一成功标准 |

建议将首期命名为“艾维艺术阅读会·创始试读季”。正式名称可在确定主理人和第一季主题后再定。

### 2. 成熟产品：年度会员制

年度产品建议采用“四季制”，每季约 12 场，全年规划 48 场常规阅读会。不要承诺每个周六都举办活动，应为春节、国庆、布撤展、场地冲突和特别活动预留弹性。

年度会员享有全年常规阅读会的预约资格；嘉宾专场、艺术家对谈、特别夜场或高成本活动可采用会员优先报名或会员专属价，不自动包含在年费内。

## 四、会员权益包

### 1. 已确认权益

| 权益 | 建议执行口径 |
|---|---|
| 创始会员礼盒 | 仅面向首批创始会员；对外标示价值 198 元前应确认实际零售价与内容清单 |
| 美术馆全年观展 | 建议覆盖馆方自主常规展览；外部租赁展、特别收费展给予会员价，具体规则须在入会前公布 |
| 24 杯手冲咖啡 | 一年内限本人使用，每次限 1 杯；限定基础手冲/茶饮范围，升级饮品补差 |
| 24 次图书借阅 | 一年内限本人使用；需明确每次可借册数、借期、逾期、遗失赔偿和图书目录 |
| 全年线下读书会 | 指全年规划的常规艺术阅读会，须预约参加；特别活动按单独规则执行 |

### 2. 建议新增权益

| 建议权益 | 价值 | 建议规则 |
|---|---|---|
| 优先预约与保留席位 | 保障年费会员的核心稀缺权益 | 常规活动提前 7 天预约；活动前 24 小时可取消，候补递补 |
| 2 张访客体验券 | 帮会员邀请朋友，也形成低成本获客入口 | 仅限首次参加者；可兑换一次访客席或抵扣访客席费用 |
| 年度 2 次会员专场导览/策展对谈 | 体现美术馆而非普通书店的差异 | 结合重点展览举办；不承诺艺术家本人出席 |
| 特别活动会员专属价 | 为高价值活动留出收费空间 | 嘉宾对谈、工作坊、特别夜场等享优先报名或专属价 |
| 季度艺术阅读资料 | 提升被策划和被陪伴的体验 | 每季主题书单、延伸观看清单与成员讨论摘要 |

### 3. 不建议现阶段承诺的权益

- 不限量咖啡或饮品。
- 免费赠书。
- 所有特别活动免费。
- 未建立稳定合作机制前的大量外部商家折扣。
- 尚未具备库存、借阅和核销能力的服务项目。

## 五、主理人合作机制

### 1. 合作原则

主理人是内容与社群动员的合作方，不是场地租赁客户；美术馆是品牌、会员关系和现场体验的主体。会员数据、报名记录、活动素材、品牌使用权和对外宣传口径归美术馆统一管理。

### 2. 合作分工

| 美术馆 | 主理人 |
|---|---|
| 主题方向最终确认、品牌与场地、报名和收款、会员服务、饮品与借阅、现场执行、活动传播、数据与复盘 | 12 场主题和书单设计、每场讨论准备、现场带领、主理人个人社群动员、内容建议 |

### 3. 收入结算原则

`主理人收入 = 已约定的基础服务费 + 读书会会费净实收 × 约定分成比例`

会费净实收应在协议中写清退款、支付手续费、优惠、赠送名额和单场访客票的处理规则。饮品、文创、书籍、艺术品及其他衍生消费不纳入分成。

### 4. 主理人筛选标准

- 对艺术阅读、人文讨论或相关主题具有持续研究和表达能力。
- 能设计连续 12 场而非单场拼凑的主题结构。
- 有稳定的现场带领能力，能让讨论不沦为单向讲座。
- 拥有可验证的个人社群或内容影响力，但不以粉丝数作为唯一标准。
- 认可美术馆品牌边界与会员数据归属。

## 六、内容与活动设计

### 1. 第一季内容要求

- 在招募前确认全部 12 场主题、核心书目、延伸材料和主理人准备要求。
- 每月形成一个小主题，三场之间彼此递进；避免 12 本书松散排列。
- 至少有一部分主题与当期展览、馆藏、艺术家或云南在地文化发生连接。
- 每场须说明阅读量，避免要求过高造成成员掉队；可设置“完整阅读”和“轻量参与”两种参与路径。

### 2. 单场建议流程

| 环节 | 建议时长 | 内容 |
|---|---:|---|
| 签到与饮品 | 20 分钟 | 核销、领取饮品、自由交流 |
| 主题导入 | 15 分钟 | 主理人说明书目、问题与当期艺术关联 |
| 共读与讨论 | 60 分钟 | 主理人引导，会员交流 |
| 延伸观看/回应 | 20 分钟 | 结合展览、图像、影像或成员分享 |
| 自由交流与反馈 | 15 分钟 | 收集现场反馈、预告下一期 |

建议每场控制在 2 小时左右。具体开始时间应优先适配昆明本地会员的周末出行节奏，并留出观展与交流时间。

## 七、市场定价建议

### 1. 市场参考

公开案例显示，线上或轻社群读书会年费通常在 199-365 元；昆明森蓝读书会以 365 元年费提供 12 次线下活动、借阅和咖啡权益；高频书店社群年卡可见 576 元；主流美术馆个人年费多处于 199-580 元区间，但通常是观展和公共活动权益，并非小规模、固定主理人的全年阅读社群。

参考来源：

- [昆明森蓝读书会会员权益](https://www.sohu.com/a/859205199_121124759)
- [樊登书店读书会年卡](https://www.sohu.com/a/920558473_121124608)
- [中央美术学院美术馆会员](https://www.cafamuseum.org/gallery/passport)
- [A4 美术馆会员](https://www.a4artmuseum.com/join-support/become-a-member/)

艾维产品包含限定社群、固定艺术主题、外部主理人和饮品服务，应高于普通大众读书会员，但不应在首期脱离昆明本地市场的支付预期。

### 2. 建议价格梯度（待馆长确认）

| 产品 | 建议价格 | 定价逻辑 |
|---|---:|---|
| 访客席 | 89 元/场 | 含基础饮品；让临时报名游客有体验入口 |
| 创始试读季早鸟 | 599 元/12场 | 前 20 名创始会员，约 50 元/场 |
| 创始试读季常规 | 699 元/12场 | 约 58 元/场，显著低于访客单场价 |
| 年度会员续费价 | 1,980 元/年 | 仅向完成首季的会员开放，作为转年费激励 |
| 年度会员常规价 | 2,280 元/年 | 四季制、全年规划 48 场常规活动 |

价格以市场定位为先；在正式销售前仍须用成本和会员容量做可持续性校验，确保不会因主理人服务费、饮品履约或实际到场率而造成长期经营压力。

## 八、预约、核销与会员规则

- 会员实名制，一人一号，不可转让或用于商业用途。
- 常规活动须预约；会员提前 7 天预约，活动前 24 小时可取消。未按时取消且缺席，可设置当期权益冻结或候补优先级下降规则。
- 访客席数量有限，优先保障会员。访客可在活动后 7 天内转为当季会员，并抵扣部分单场费用。
- 咖啡、借阅、观展和活动权益须有统一会员编号或电子核销记录。
- 礼盒、咖啡、借阅和体验券均须写明有效期、使用范围、是否可补发和遗失处理。
- 活动照片、成员发言和社群内容的使用须在报名规则中说明并征得必要同意。

## 九、招募与传播

### 1. 对外沟通重点

- 这是一个在美术馆发生的艺术阅读社群，而非单纯课程或书友聚会。
- 第一季 12 个主题和书单提前公开，让潜在会员判断自己是否愿意长期参与。
- 创始会员限额、礼盒和未来年度会员续费优先权是首期核心转化点。
- 突出“固定周六、稳定主理人、艺术主题、阅读空间、观展与咖啡”的完整体验。

### 2. 建议招募路径

1. 先发布主理人招募或定向邀约，确认主理人与 12 场内容框架。
2. 制作创始试读季说明页：定位、书单、日期、权益、价格、规则、主理人介绍。
3. 组织 1 场开放体验会或主题预热分享，收集潜在会员名单。
4. 面向美术馆既有观众、展览观众、艺术院校/机构、咖啡和阅读社群进行定向招募。
5. 首期结束前 4 周启动年度会员续费和会员推荐机制。

| 类别 | 待确认事项 |

| 图书 | 可借阅书目、借阅册数、借期、押金/赔偿、库存管理与核销方式 |
| 饮品 | 基础饮品菜单、出品能力、单次服务上限、咖啡权益核销方式 |
| 主理人 | 候选名单、服务费、分成比例、12 场交付、替补和取消条款 |
| 价格 | 试读季价格、访客席价格、年费转换价格、退款与转让规则 |
| 内容 | 第一季 12 场主题、书单、阅读量、主理人介绍与活动日期 |
| 系统 | 会员登记、预约、核销、退款、数据统计是否可由现有运营系统支持 |

## 十一、相对排期

| 阶段 | 建议时间 | 完成标准 |
|---|---|---|
| 立项与主理人确定 | T-6 至 T-5 周 | 主理人签署合作意向，12 场框架完成 |
| 内容、权益与价格确认 | T-5 至 T-4 周 | 书单、价格、会员规则和权益边界可对外说明 |
| 招募材料与开放体验会 | T-4 至 T-2 周 | 招募页上线，完成一次开放体验与线索收集 |
| 创始会员招募与活动准备 | T-2 至 T-0 周 | 达到最低开班人数，完成空间、饮品、借阅和核销演练 |
| 创始试读季运营 | T 至 T+12 周 | 完成 12 场活动并形成每场记录与季末复盘 |
| 年度会员转化 | T+8 至 T+12 周 | 向试读季会员开放续费，基于数据决定是否进入全年制 |

## 十二、首期评估指标

| 维度 | 首期应记录的指标 |
|---|---|
| 招募 | 咨询人数、体验会到场、创始会员转化率、获客渠道 |
| 参与 | 每场预约数、实际到场率、取消率、候补转化率、复到率 |
| 内容 | 主题满意度、主理人满意度、书单完成度、成员讨论参与度 |
| 消费 | 咖啡核销率、借阅核销率、访客席收入、特别活动转化 |
| 社群 | 成员推荐人数、社群活跃度、年度续费意向 |
| 经营 | 会费净实收、主理人结算、饮品成本、单场服务问题与投诉 |

## 十三、立项决策建议

建议先批准“创始试读季”的方案设计与主理人招募，不直接承诺全年运营。只有在以下条件满足后，才开放年度会员销售：

1. 已确定主理人与 12 场完整内容框架。
2. 六楼阅读、饮品、借阅、预约和核销服务可稳定履约。
3. 创始试读季达到最低开班人数，且体验会反馈支持当前定价。
4. 美术馆与主理人签署清晰的合作与结算规则。
