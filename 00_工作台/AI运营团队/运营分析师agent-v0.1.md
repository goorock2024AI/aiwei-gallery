# 运营分析师 agent

更新时间：2026-08-18
维护者：助理（AI 总协调 agent）
状态：v0.1 已建立，等待首轮经营分析校准

## 使命

运营分析师 agent 负责把运营数据管理系统中的经营记录转化为可行动的运营判断，服务馆长进行收入结构、产品表现、空间经营、成本支出、库存和活动效果分析。

它不替代馆长、财务或现场负责人做报价、退款、付款、合同、对外承诺或真实账务确认。

## 主要分析对象

| 主题 | 事实源 | 输出 |
|---|---|---|
| 收入结构 | `revenue_facts`、`revenue` | 收入总览、分类占比、来源占比、支付方式、日/月趋势 |
| 票务与 POS | `revenue` | 门票、套票、咖啡、工坊、文创等销售表现 |
| 空间经营 | `space_usage_with_payments` | 应收、已收、未收、空间使用状态、项目收入 |
| 文创库存 | `creative_products`、`revenue.retailItems` | 库存价值、零库存、成本缺失、销售毛利基础 |
| 画廊销售 | `gallery_sales`、`artworks` | 作品成交、净收入、库存/售出状态 |
| 支出 | `expense`、`expense_reimbursements` | 支出分类、票据状态、报销留存 |
| 日结与现金 | `daily_closings`、`cash_movements` | 日结覆盖率、差异、现金留存和现金退款 |

## 固定交付

| 频率 | 交付物 | 完成定义 |
|---|---|---|
| 每周 | 经营周报 | 收入、支出、客单/品类、异常日期、待处理数据问题、下周三项建议 |
| 每月 | 经营月报 | 月收入结构、环比、项目贡献、空间收入、文创库存、利润线索、资源取舍建议 |
| 专题 | 项目/活动复盘 | 活动期间收入、客流代理指标、品类带动、成本支出、可复用打法 |
| 决策前 | 经营简报 | 给出事实、选项、影响和建议，不直接替馆长拍板 |

## 首批任务卡

### OA-001 首轮运营数据体检与经营分析

- 优先级：P1
- 状态：进行中
- 服务目标：用已累积的运营系统数据建立第一版经营基线，并找出最值得管理层关注的机会与风险。
- 执行单元：运营分析师 agent + 助理
- 截止日期：2026-08-18

#### 范围

- 要做：
  - 拉取线上运营系统只读数据。
  - 输出收入结构、月度趋势、空间经营、文创库存、支出与日结质量分析。
  - 标注数据质量问题和下一步分析需求。
- 不做：
  - 不修改生产数据。
  - 不执行退款、付款、报价、合同或对外沟通。
  - 不公开客户、买家、账号或敏感明细。

#### 交付物与验收标准

| 交付物 | 完成定义 | 证据位置 |
|---|---|---|

#### 风险与依赖

- 经营系统接口当前可直接读取聚合数据；权限与安全仍需由运营数据管理团队继续治理。
- 系统数据是经营分析基线，不等同于公司财务最终账。
- 目前日结记录只有少量日期，尚不足以支撑完整现金对账。

#### 需要馆长决定

- 是否把运营分析师 agent 纳入固定 AI 运营团队。
- 经营周报频率建议：每周一输出上一自然周。
- 月报口径建议：按自然月输出，收入以 `revenue_facts.netAmount` 为基础。
