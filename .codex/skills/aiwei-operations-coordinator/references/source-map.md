# 艾维事实源地图

## 优先读取

| 主题 | 事实源 | 使用规则 |
|---|---|---|
| 全馆概况 | `INDEX.md`、`00_工作台/艾维美术馆基础信息与运营状态.md` | 需要全局判断或空间/展览现状时读取 |
| 项目状态 | `registry/INDEX.md`、`registry/**/*.md` | 本地项目状态的主要来源；线上台账不一致时标为冲突 |
| 展览与活动 | `02_展览活动/*.md` | 读取具体专题文件，不扫描非 Markdown 大文件 |
| 经营计划与工作日志 | `00_工作台/近期工作计划/*.md`、`00_工作台/工作日志/*.md` | 用于执行节点、版本记录和近期变化 |
| 运营数据系统 | `00_工作台/运营数据管理/*.md`、对应应用代码 | 技术需求交给运营数据管理团队；总协调只做业务验收 |
| 内容 | `aiwei-content/`、`03_内容传播/` 的 Markdown 文件 | 用于内容和观众服务任务；发布记录须标明确认状态 |
| AI 团队 | `00_工作台/AI运营团队/` | 团队边界、演化和总工作盘 |

## 数据与安全

- 经营数据以当前正式运营系统/API 的实时记录为准；不要用旧文档覆盖实时记录。
- 项目规则中出现 Supabase 与腾讯云 API 两种历史表述时，先核验数据源与写入权限，不自行迁移或写入。
- 不在输出、工作盘或外部材料中写入密钥、个人信息或完整敏感经营明细。
