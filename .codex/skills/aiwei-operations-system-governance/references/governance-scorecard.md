# 运营数据系统治理评分卡

## P0 项

| 项目 | 合格定义 | 证据 |
|---|---|---|
| API 鉴权 | 未授权请求不能读写经营数据；关键写入接口校验角色 | 接口测试、代码位置、失败响应 |
| HTTPS | 业务入口强制 HTTPS，无浏览器安全警告 | 浏览器/HTTP 检查 |
| 自动备份 | 连续 7 日备份成功，完成一次恢复验证 | 备份目录、日志、恢复记录 |
| 退款/作废 | 每笔动作有原单、状态、原因、操作人、时间 | 数据表字段、UI 流程、操作日志 |
| 库存扣减 | 文创销售后库存可核；退款/作废可反向处理 | 库存流水、异常处理 |
| 采购入库 | 入库有供应商/来源、商品、数量、成本或金额、操作人、时间、备注或凭证关联，并形成库存流水 | 入库记录、库存流水、操作日志 |
| 日结 | 能导出日收入、支付方式、退款、现金差异、操作人 | 日结报表和样例 |

任一 P0 项不通过，即不得作为“生产上线放行”依据，必须标为 P0 阻断或等待授权决策。

## 最低测试矩阵

### API 鉴权

| 身份 | 读取 | 创建 | 修改 | 删除/作废 | 导出 |
|---|---|---|---|---|---|
| 未登录 | 应失败 | 应失败 | 应失败 | 应失败 | 应失败 |
| viewer | 按授权范围 | 应失败 | 应失败 | 应失败 | 按授权范围 |
| editor | 按授权范围 | 按授权范围 | 按授权范围 | 应失败或需审批 | 按授权范围 |
| admin | 按授权范围 | 按授权范围 | 按授权范围 | 按授权范围或需审批 | 按授权范围 |

每格都要保留成功或失败响应证据。

### HTTPS

- HTTP 应跳转或被替换为 HTTPS。
- 证书有效且无浏览器安全警告。
- 页面无混合内容阻断。
- 记录证书有效期和反向代理位置。

### 备份

- 每日自动备份。
- 连续 7 日成功。
- 备份至少有非同机留存或明确替代方案。
- 失败有告警或人工检查机制。
- 至少一次恢复到隔离环境，并验证核心表记录数。

### 财务、库存、日结红线

退款、作废、库存变更、采购入库和日结不得无日志，不得物理删除原单，不得缺少操作人和时间；缺任一项即 P0 未通过。

## P1 项

| 项目 | 合格定义 | 证据 |
|---|---|---|
| 应收看板 | 场租、合作、赞助按应收日、状态、账龄追踪 | 查询结果、页面或报表 |
| 月度经营仪表盘 | 收入结构、客流、费用、应收、渠道可比较 | 报表样例 |
| 版本纪律 | 每次上线有版本、说明、验证、回滚方式 | Git、日志、发布记录 |
| 数据字典 | 关键表和字段有口径说明 | 文档和代码一致 |
